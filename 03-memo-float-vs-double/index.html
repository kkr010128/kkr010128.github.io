float보다 double을 더 많이 사용하는 이유는 무엇일까?

float와 double의 차이, 32비트에서 64비트 환경으로 변화하면서 double이 기본 선택이 된 이유

Dohyeon Kim 2026년 8월 6일 · 2분 읽기
Notes CS DataType Memory

Q. float는 4바이트이고 double은 8바이트인데 왜 double을 더 많이 사용할까?

강의 중 실수형 자료형을 설명하면서 float는 4바이트, double은 8바이트라고 배웠다.

메모리만 생각하면 float를 사용하는 것이 더 효율적일 것 같은데, 실제 코드에서는 오히려 double이 기본처럼 사용되는 경우가 많다.

왜 이런 차이가 생긴 것일까?

A. 현대 컴퓨터에서는 메모리보다 정확도가 더 중요해졌기 때문이다.

과거에는 메모리가 매우 부족했다.

16비트, 32비트 컴퓨터 시절에는 RAM이 수 MB 수준인 경우도 많았기 때문에 4바이트와 8바이트의 차이가 매우 컸다.

하지만 현재 대부분의 PC와 서버는 64비트 환경에서 수 GB에서 수십 GB 이상의 메모리를 사용한다.

이제는 실수 하나를 저장할 때 추가되는 4바이트보다 계산 정확성이 훨씬 중요한 요소가 되었다.

float와 double의 차이

자료형 크기 유효 자릿수 특징
float 4 Byte 약 7자리 메모리 사용량이 적음
double 8 Byte 약 15~16자리 높은 정밀도

예를 들어 다음과 같은 계산을 수행하면 차이를 쉽게 볼 수 있다.

float a = 0.1f;
double b = 0.1;

printf("%.20f\n", a);
printf("%.20lf\n", b);

두 값 모두 내부적으로는 정확한 0.1을 표현하지 못하지만, double이 훨씬 작은 오차를 가진다.

32비트에서 64비트로 바뀌며 무엇이 달라졌을까?

32비트 환경에서는 메모리 공간이 제한적이었다.

따라서 가능한 작은 자료형을 사용하는 것이 중요한 최적화 방법이었다.

하지만 64비트 환경에서는 다음과 같은 변화가 생겼다.

  • 메모리 용량이 크게 증가
  • CPU의 연산 성능 향상
  • 부동소수점 연산 장치(FPU)의 발전
  • 대부분의 컴파일러와 라이브러리가 double 중심으로 최적화

즉, 메모리를 아끼는 것보다 계산 결과의 신뢰성을 확보하는 것이 더 중요한 시대가 된 것이다.

오히려 double이 더 자연스러운 경우도 있다.

C와 C++에서는 실수 리터럴의 기본 타입이 double이다.

double a = 3.14;   // 기본

float b = 3.14f;   // f를 붙여야 float

또한 대부분의 수학 함수도 double을 기준으로 제공된다.

sqrt()
sin()
cos()
log()

이 함수들은 기본적으로 double을 사용하므로 float를 전달하면 내부에서 형 변환이 발생할 수 있다.

그렇다면 float는 언제 사용할까?

float가 사라진 것은 아니다.

메모리 사용량이 매우 중요한 환경에서는 여전히 많이 사용된다.

대표적인 예시는 다음과 같다.

  • 게임 엔진에서 수백만 개의 정점(Vertex) 저장
  • GPU 연산
  • 머신러닝 모델의 FP16, FP32 연산
  • 모바일 및 임베디드 시스템
  • 센서 데이터 처리

이처럼 동일한 데이터를 매우 많이 저장해야 하는 환경에서는 4바이트 차이만으로도 수십~수백 MB 이상의 메모리를 절약할 수 있다.

자주 하는 오해

  • 64비트 운영체제에서는 float도 8바이트가 된다.
    • 아니다. 운영체제와 관계없이 float는 일반적으로 4바이트, double은 8바이트이다.
  • double이 항상 더 빠르다.
    • 반드시 그렇지는 않다. 하지만 현대 CPU에서는 double이 특별히 느리지 않으며, 대부분의 일반적인 프로그램에서는 성능 차이를 체감하기 어렵다.
  • 메모리를 아끼려면 항상 float를 사용해야 한다.
    • 아니다. 일반적인 애플리케이션에서는 메모리 절약보다 정밀도가 더 중요하다.

정리

  • float는 4바이트, double은 8바이트이다.
  • 현대 컴퓨터에서는 메모리보다 계산 정확성이 더 중요해졌다.
  • 대부분의 실수 연산과 라이브러리는 double을 기준으로 동작한다.
  • 일반적인 애플리케이션에서는 double을 사용하는 경우가 많다.
  • 메모리 사용량이 매우 중요한 환경에서만 float를 적극적으로 사용하는 것이 일반적이다.
