함수(Function)

함수란?

여러 문장을 하나의 이름으로 묶어 필요할 때 호출하여 사용하는 코드 블록이다.

함수를 사용하는 이유

  • 코드 재사용
  • 중복 제거
  • 유지보수 향상
  • 가독성 향상
  • 기능 단위 분리

함수의 종류

내장 함수(Built-in Function)

Python에서 기본 제공하는 함수

대표 함수

  • print()
  • input()
  • len()
  • max()
  • min()
  • sum()
  • range()

사용자 정의 함수(User Defined Function)

개발자가 직접 만드는 함수

def 함수이름(매개변수):
    실행문
    return 결과

함수 정의

기본 구조

def add(a, b):
    return a + b

호출

result = add(10, 20)

함수 호출(Call)

형태 의미
add 함수 객체 참조
add() 함수 실행

반환(Return)

역할

  • 함수 종료
  • 호출한 곳으로 값 반환
def square(x):
    return x * x

return 생략

def func():
    pass

↓

None

반환

여러 값 반환

def swap(a, b):
    return b, a

실제로는 Tuple 반환

x, y = swap(10, 20)

매개변수(Parameter)

def plus(a, b):
    return a+b

기본값(Default Parameter)

def plus(a, b=1):
    return a+b

호출

plus(5)

↓

6

키워드 인수(Keyword Argument)

plus(b=10, a=20)

순서와 관계없이 호출 가능

인수 전달 방식

Scalar

값 전달

a = 10

함수 내부에서 변경해도 원본 변경 없음

Vector

참조 전달

li = [1,2,3]

리스트 내부 수정 시 원본도 변경

순수 함수(Pure Function)

특징

  • 동일한 입력 → 동일한 출력
  • 외부 상태 변경 없음
  • Side Effect 없음

비순수 함수(Impure Function)

외부 상태를 변경하는 함수

예

  • 전역 변수 수정
  • 파일 저장
  • 리스트 변경

Unpacking

Sequence

numbers = [10,20]

func(*numbers)

↓

func(10,20)

Dictionary

person = {
    "name":"Kim",
    "age":20
}

func(**person)

가변 매개변수

*args

여러 개의 위치 인수를 Tuple로 받는다.

def total(*args):
    return sum(args)

**kwargs

여러 개의 키워드 인수를 Dictionary로 받는다.

def profile(**kwargs):
    print(kwargs)

재귀 함수(Recursive Function)

자기 자신을 호출하는 함수

반드시 종료 조건이 필요하다.

합계

def total(n):
    if n == 1:
        return 1
    return total(n-1) + n

팩토리얼

def factorial(n):
    if n == 0:
        return 1
    return factorial(n-1) * n

피보나치

def fibonacci(n):
    if n <= 2:
        return 1
    return fibonacci(n-1) + fibonacci(n-2)

하노이의 탑

대표적인 재귀 알고리즘

이동 횟수

2ⁿ - 1

pass

아직 구현하지 않은 함수

def temp():
    pass

Type Hint

매개변수와 반환형을 명시할 수 있다.

def add(a: int, b: int) -> int:
    return a+b

Annotation

def clip(
    text: str,
    max_len: int = 80
) -> None:

문서화 및 정적 분석에 활용된다.

Docstring

함수 설명 작성

def add(a, b):
    """
    두 수를 더한다.
    """
    return a+b

확인

help(add)

함수형 프로그래밍

고차 함수(Higher-order Function)

함수를

  • 인수로 전달
  • 반환값으로 반환

할 수 있는 함수

def calc(func, a, b):
    return func(a, b)

lambda

익명 함수

lambda x: x*x

특징

  • 한 줄 함수
  • 이름 없음
  • 간단한 연산에 사용

map()

모든 요소 변환

result = map(func, iterable)

예

list(map(lambda x:x*x, data))

filter()

조건을 만족하는 요소만 선택

result = filter(func, iterable)

예

list(filter(lambda x:x%2==0, data))

reduce()

모든 데이터를 하나의 값으로 누적

from functools import reduce

예

reduce(lambda x,y:x+y, data)

zip()

여러 Iterable을 묶는다.

zip(a, b)

예

for x, y in zip(names, scores):
    print(x, y)

중첩 함수(Nested Function)

함수 안에 함수를 정의할 수 있다.

def outer():

    def inner():
        pass

    inner()

Closure

외부 함수의 지역 변수를 기억하는 함수

def calc():

    a = 3

    def mul(x):
        return a*x

    return mul

일급 함수(First-Class Function)

Python 함수는

  • 변수 저장 가능
  • 매개변수 전달 가능
  • 반환 가능
  • 런타임 생성 가능

Decorator

Decorator란?

기존 함수를 수정하지 않고 기능을 추가하는 문법

@decorator
def func():
    ...

동작

func
 ↓
decorator(func)
 ↓
새로운 함수

활용

  • Logging
  • 실행 시간 측정
  • 인증(Authentication)
  • 권한 검사
  • 캐싱(Cache)

lru_cache()

메모이제이션 제공

from functools import lru_cache

@lru_cache()
def fibonacci(n):
    ...

장점

  • 동일한 계산 재사용
  • 재귀 성능 향상
  • 실행 시간 단축

핵심 암기

  • def : 함수 정의
  • return : 결과 반환
  • *args : 가변 위치 인수(tuple)
  • **kwargs : 가변 키워드 인수(dict)
  • pass : 빈 구현
  • lambda : 익명 함수
  • map() : 데이터 변환
  • filter() : 조건 선택
  • reduce() : 누적 계산
  • zip() : 여러 Iterable 묶기
  • global : 전역 변수 사용
  • nonlocal : 외부 함수 변수 사용
  • Closure : 외부 지역 변수 유지
  • Decorator : 함수 기능 확장
  • lru_cache() : 메모이제이션
