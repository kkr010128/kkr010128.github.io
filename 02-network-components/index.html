Network Components

LAN/WAN/VPN 개념과 NIC, 스위치, 라우터, 로드밸런서 등 네트워크 구성 장비 정리

Network AutoEverSW

=> (강사님): 예전에는 LAN • MAN•WAN이 사용하는 프로토콜과 기술이 달라 구분 가능했으나 현재는 Ethernet으로 통합되어 관리의 범위를 기준으로 구분한다.

  • 자체 인프라를 사용한 구축 → MAN
  • 통신사의 인프라 사용한 구축 → WAN

    LAN

  • 비교적 소규모의 네트워크
  • 스위치와 같은 간단한 장비로 연결
  • 이더넷 기반 전송 기술 사용
    • 예전에는 다양한 기술이 사용되었음
  • 자신 소유의 건물 또는 대지에 직접 구축한 선로로 동작시키는 네트워크

    WAN

  • 먼 거리에 있는 네트워크를 연결
  • 멀리 떨어진 LAN을 서로 연결하거나 인터넷에 접속하기 위한 네트워크
  • 통신 사업자로부터 회선을 임대해 사용
    • 넓은 범위이므로 직접 구축하는 경우는 거의 없음

2 ) 인터넷 회선

일반 인터넷 회선

  • 인터넷 접속을 위해 통신 사업자와 연결하는 회선
  • 가입자와 통신 사업자 간 직접 연결 구조가 아님
  • 전송 선로 공유 기술을 이용(Multiplexing)
  • 통신 사업자까지 연결한 회선을 공유하는 구조 → 내부 선로가 직접 연결되는 구조라 인터넷 전용 회선처럼 보일 수 있음
  • 인터넷 회선의 속도는 전송 가능한 최대 속도이며, 전용 회선과 달리 해당 속도를 보장하지 않

    전용 회선

  • 가입자와 통신 사업자 간의 대역폭을 보장해주는 서비스
  • 대역폭을 보장해주는 기술 중 하나 → TDM(Time Devision Multiplaxing - 시분할 다중화)
  • 저속과 고속으로 구분하기도 함
  • LLCF (Link Loss Carry Forward) → 한쪽의 링크가 다운되는 것을 감지해 반대 쪽 링크도 다운시키는 기능 => (강사님): 게임 접속자가 끊겼는지 핑을 보내면서 확인하고, 반응이 없다면 끊어서 연결 가능한 유저 수를 확보하려는 방법이다.

    인터넷 전용 회선

  • 인터넷 연결 회선에 통신 대역폭을 보장해주는 것

    VPN

  • Virtual Private Network
    • 가상으로 물리적 전용선 같은 효과를 주는 가상 네트워크
  • 여러 방법으로 구현되며, 가입자 입장에서의 기술과 통신 사업자 입장에서의 기술이 별도로 발전
  1. 통신 사업자 VPN
    • 전용선(Leased Line)은 계약한 대역폭을 항상 보장함.
    • 하지만 가입자가 계약된 대역폭을 항상 100% 사용하는 것은 아님.
    • 사용하지 않는 대역폭에도 비용을 지불하므로 비용 낭비가 발생할 수 있음.
    • 이를 줄이기 위해 통신사업자의 공용망을 여러 가입자가 함께 사용함.
    • 이때 가입자별 트래픽이 섞이지 않도록 논리적으로 분리함.
    • 이러한 방식 중 하나가 MPLS VPN임.
    • MPLS VPN은 공용망을 사용하면서도 전용선과 유사한 연결 환경을 제공함.
    • 전용선보다 비용을 줄이면서 먼 지역의 지점들을 연결할 때 사용함.

    전용선은 대역폭을 보장하지만 비용이 높을 수 있으며, 이를 보완하기 위해 공용망에서 가입자별 트래픽을 분리하는 MPLS VPN을 사용함.

  2. 가입자 VPN
    • 인터넷과 같은 공용망을 이용해 가상의 사설망을 구축함.
    • 데이터를 암호화하여 외부에서 내용을 확인하거나 변조하지 못하도록 보호함.
    • 별도의 전용선을 설치하지 않아 비용이 저렴함.
    • 원격 근무, 재택근무, 외부에서 사내망 접속 등에 주로 사용함.
    • 대표적인 프로토콜로 IPsec VPN, SSL VPN, OpenVPN, WireGuard 등이 있음.

    공용 인터넷을 이용하면서도 암호화를 통해 안전하게 사설망처럼 사용할 수 있도록 하는 기술임.

VPN 과 일반 네트워크의 속도 차이?

VPN은 목적지의 주소를 알고 있기 때문에 최적의 라우팅 경로로 이동하게 됨 암호화와 복호화를 진행하더라도 라우팅 속도가 빠르기 때문에 VPN의 통신 속도가 일반 네트워크 대비 우수함

3 ) 네트워크 구성 요소

NIC (Network Interface Card)

  • 컴퓨터를 네트워크에 연결하기 위한 하드웨어 장치

  • 일반적으로 온보드 형태로 네트워크 인터페이스 카드가 장착되어 있어 실제 장착하는 경우 드뭄

  • 역할
    • 직렬화(Serialization)
      • 전기적 신호 ←→ 데이터 신호 형태로 변화해주는 역할 => (강사님): 블랙박스를 예로 들자면, 항공기 또는 선박의 블랙박스에 기록된 항적은 해당 블랙박스 제조사가 가진 Class 파일들을 가지고 있어야 해독이 가능함 (조작 방지)
    • MAC Address
      • 물리적인 고유 주소
    • Flow Control
      • 흐름 제어
      • 처리중인 데이터로 인해 새로운 데이터를 받지 못하는 상황을 방지
        • 상황을 상대방에 알려 통신 중지를 요청함 => (강사님): 포트리스 게임에서 상대방이 통신이 느린 모뎀을 쓸 때 “너 느리니까 나가”라고 했었음

          케이블 & 커넥터

  • 케이블 규격
    • 속도 채널 타입 / 속도 채널 타입
    • 1000BASE-T / 10GBASE-T → 속도는 1000Mbps, 트위스트 페어 케이블 사용하는 Ethernet 표준
    • 1000BASE-SX / 10GBASE-SR → 속도는 1000Mbps, 광 케이블 사용하는 Ethernet 표준

Hub

  • 케이블과 동일한 1계층 장비
  • 멀어질 수록 줄어드는 전기 신호를 재생성해줌
  • 여러 대의 장비를 연결
  • 허브는 들어온 신호를 단순히 모든 포트로 내보냄 (Broadcasting)
    • 네트워크에 접속된 모든 노드가 경쟁하므로 전체 성능이 줄어드는 문제가 있음
    • 패킷이 무한 순환하여 네트워크 전체를 마비시키는 루프와 같은 다양한 장애 원인이 될 수 있음

Switch

  • Hub와 동일하게 여러 장비를 연결
  • 통신을 중재하는 2계층 장비
  • 허브의 역할을 수행함
  • Switching Hub 라고도 함
  • MAC 을 이해할 수 있음 → 한 번 데이터를 전송한 포트에 연결된 장비 주소를 학습 다음에 다른 포트에서 해당 장비에게 전달 시 Broadcasting이 아닌 Unicasting(1:1)을 수행

Router

  • 내부 네트워크가 아닌 다른 네트워크와 통신 가능하도록 해줌
  • 3계층 장비
  • Broadcast와 Multicast를 컨트롤함 → 원격지로 필요 없는 패킷이 전달되지 않도록
  • 불분명한 주소로 통신 시도 시 데이터를 버림
  • 정확한 방향으로 패킷이 전송되도록 경로를 지정, 최적의 경로로 패킷을 Fowarding
  • 이와 유사한 L3 Switch나 공유기는 쉽게 찾아볼 수 있음

Load Balancer

  • OSI 4계층에서 동작하는 장비
  • 최근에는 7계층에서 동작하는 것도 있음
  • Application 형태의 LoadBalancer도 존재함 (7계층에서 동작) → 원래 Application Delivery Controller 라고 함
  • 4계층 포트 주소를 확인하는 동시에 IP 주소를 바꿀 수 있음 → 목적지의 IP 주소를 말함
    • 패킷이 전달 되다가 다른 주소의 IP 주소로 전달 되게끔
  • 여러 대의 동일한 기능을 수행하는 서버들을 연결해 사용
    • 요청 수신 시 IP 주소 변경을 통해 부하를 분산함
  • Health Check와 대용량 세션 처리 기능을 수행하기도 함

보안 장비

  • 정보 전달 목적이 아닌 정보를 잘 제어하고 공격을 방어하는 데 초첨을 둠
  • 방어의 목적, 설치 위치에 따라 다양하게 구분 됨
  • 대표적으로 방화벽이 있음
    • OSI 7 계층의 4계층에서 동작
    • 방화벽을 통과하는 패킷의 3, 4 계층 정보(IP와 Port)를 확인,
    • 패킷을 보안 정책과 비교해 버리거나 Forwarding 함

공유기

  • 간단한 방화벽 기능을 한 곳에 모아둔 장비
    • 2계층 스위치, 3계층 라우터, 4계층 NAT
  • 내부 구성
    • 스위치
    • 무선
    • 라우터 회로
  • 내부적으로는 크게 Switch, Wireless AP, Router 부분으로 구성되는 복잡한 장비

모뎀

  • 원거리 통신을 가능하도록 하는 장비
  • 짧은 거리, 먼 거리를 통신할 수 있는 기술이 다르기에 이 기술들을 변환해주는 장비임
