Copy

참조 복사

a = [1,2,3]
b = a

같은 객체 참조

얕은 복사(Shallow Copy)

import copy

b = copy.copy(a)

또는

a[:]

특징

  • 1단계만 복사
  • 내부 객체는 공유

깊은 복사(Deep Copy)

import copy

b = copy.deepcopy(a)

특징

  • 모든 객체 재귀 복사
  • 독립적인 객체 생성

Weak Reference

import weakref

특징

  • 참조 횟수 증가 없음
  • 메모리 누수 방지
  • 객체가 제거되면 None 반환

생성

ref = weakref.ref(obj)
