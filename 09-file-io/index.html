파일 처리(File Handling)

파일 처리 과정

파일 열기(Open)
        │
        ▼
파일 읽기 / 쓰기
        │
        ▼
파일 닫기(Close)

대표 함수

  • open()
  • read()
  • write()
  • close()

open()

기본 형태

open(path, mode, encoding)

예

file = open("test.txt", "r", encoding="utf-8")

파일 모드

모드 설명
r 읽기(기본)
w 쓰기(기존 내용 삭제)
a 이어쓰기(Append)
x 새 파일 생성
b Binary Mode
t Text Mode(기본)
+ 읽기/쓰기

파일 경로(Path)

절대 경로

루트부터 전체 경로 지정

C:\data\test.txt

또는

/home/user/test.txt

상대 경로

현재 작업 디렉터리 기준

./

현재 디렉터리

../

상위 디렉터리

파일 쓰기

write()

with open("test.txt","w",encoding="utf-8") as f:
    f.write("Hello")

writelines()

여러 줄 기록

lines = [
    "Python\n",
    "Java\n"
]

f.writelines(lines)

join()

f.write("\n".join(lines))

파일 읽기

read()

전체 읽기

content = f.read()

readline()

한 줄 읽기

line = f.readline()

readlines()

모든 줄을 List로 반환

lines = f.readlines()

반복문 읽기

for line in f:
    print(line)

지정한 크기만 읽기

f.read(100)

100 Byte 읽기

Context Manager

with

with open(
    "test.txt",
    "r",
    encoding="utf-8"
) as f:

    print(f.read())

장점

  • 자동 close()
  • 예외 발생 시에도 안전
  • 코드 간결

CSV

CSV란?

Comma Separated Values

텍스트 기반 표 형식 데이터

CSV 읽기

import csv

with open(
    "test.csv",
    encoding="utf-8"
) as f:

    reader = csv.reader(f)

    for row in reader:
        print(row)

CSV 쓰기

import csv

with open(
    "test.csv",
    "a",
    newline=""
) as f:

    writer = csv.writer(f)

    writer.writerow([
        1,
        "Python"
    ])

delimiter

구분자 변경

csv.reader(
    f,
    delimiter=";"
)

Binary File

Binary Mode

쓰기

with open(
    "test.bin",
    "wb"
) as f:

    f.write(
        "Python".encode()
    )

읽기

with open(
    "test.bin",
    "rb"
) as f:

    print(
        f.read().decode()
    )

파일 압축

zipfile

압축

import zipfile

with zipfile.ZipFile(
    "test.zip",
    "w"
) as z:

    z.write("test.txt")

압축 해제

zipfile.ZipFile(
    "test.zip"
).extractall()

tarfile

압축

import tarfile

with tarfile.open(
    "test.tar.gz",
    "w:gz"
) as tar:

    tar.add("test.txt")

압축 해제

tarfile.open(
    "test.tar.gz"
).extractall()

핵심 암기

  • open() : 파일 열기
  • read() : 전체 읽기
  • readline() : 한 줄 읽기
  • readlines() : List 반환
  • write() : 파일 기록
  • writelines() : 여러 줄 기록
  • with : 자동 close()
  • csv.reader() : CSV 읽기
  • csv.writer() : CSV 쓰기
  • pickle.dump() : 객체 저장
  • pickle.load() : 객체 복원
  • zipfile : ZIP 압축
  • tarfile : TAR 압축
  • openpyxl : Excel 처리
