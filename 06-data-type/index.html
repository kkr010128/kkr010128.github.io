1. 데이터의 기본 개념 (Data Fundamentals)

1.1 용어 정의

  • Literal: 프로그램 상에서 개발자가 직접 입력하는 값.
  • Variable(변수): 값을 저장할 수 있는 메모리 상 공간의 이름.
  • DataType(자료형): 변수에 저장할 수 있는 데이터의 종류와 저장 방법 및 크기.

1.2 데이터 분류

  1. 데이터 개수에 따른 분류
    • Scala Data: 1개의 데이터 (int, float, bool 등).
    • Vector Data (Collection): 0개 이상의 데이터 집합 (list, tuple, dict 등).
  2. 데이터 형태에 따른 분류
    • 정형 데이터: RDBMS 테이블이나 스프레드시트처럼 고정된 행/열 구조를 가진 데이터.
    • 비정형 데이터: 텍스트, 이미지, 동영상 등 고정된 구조가 없는 데이터.
    • 반정형 데이터: HTML, JSON처럼 데이터 내부에 메타데이터를 포함한 구조.

2. Scala Data (기본 자료형)

2.1 bool (부울형)

True와 False 중 하나를 저장하며, 조건문과 논리 연산의 기초가 됩니다.

  • 문법: bool(값)
  • 특징: 0이 아닌 숫자나 데이터가 있는 컬렉션은 True, 0이나 빈 컬렉션([], {}, "" 등)은 False로 간주됩니다.
  • 예제 및 결과:
print(bool([]))    # 결과: False (빈 리스트)
print(bool(3))     # 결과: True (0이 아닌 정수)
print(bool(3 + 4)) # 결과: True (연산 결과가 7이므로 True)

2.2 수치 데이터 (Numeric Types)

  • int (정수): 메모리가 허용하는 한 무한대 크기 지원. int(실수)는 소수점을 버립니다.
  • float (실수): 8바이트 부동 소수점 방식. 디지털 방식의 한계로 인해 0.2 == (1.0 - 0.8)은 False가 나올 수 있는 정밀도 오차가 존재합니다.
  • complex (복소수): 실수부와 허수부(j 사용)로 구성. conjugate()로 켤레 복소수를 구합니다.

2.3 주요 수학 함수 (Math Module)

수학적 계산을 위해 import math가 필요합니다.

함수 설명 문법 예제 결과
ceil(x) 올림 math.ceil(x) math.ceil(1.2) 2
floor(x) 내림 math.floor(x) math.floor(1.7) 1
pow(x, y) x의 y승 math.pow(x, y) math.pow(3, 2) 9.0
sqrt(x) 제곱근 math.sqrt(x) math.sqrt(9) 3.0
fabs(x) 절대값 math.fabs(x) math.fabs(-5) 5.0

2.4 Decimal & Random

  • decimal.Decimal: float의 정밀도 문제를 해결하기 위해 사용합니다.
  • random: 난수 생성 모듈입니다.

print(random.randint(1, 10)) # 예: 7

3. Vector Data (시퀀스 및 컬렉션)

3.1 공통 연산 (Sequential Type Operations)

  • Indexing: msg (첫 번째), msg[-1] (마지막).
  • Slicing: [start:end:step] (start부터 end 앞까지 step 간격으로 추출).
  • 예제 및 결과:
msg = "Korea"
print(msg[1:3])   # 결과: 'or'
print(msg[::-1])  # 결과: 'aeroK' (문자열 뒤집기)

3.2 str (문자열)

문자열은 Immutable(변경 불가능) 하므로 내부 값을 직접 수정할 수 없습니다.

메서드 설명 문법 예제 결과
find(sub) 문자열 위치 검색 s.find('a') "abc".find('b') 1 (없으면 -1)
replace(old, new) 문자열 치환 s.replace('a', 'b') "apple".replace('p', 'P') 'abble'
split(sep) 구분자로 분리 s.split(',') "a,b,c".split(',') ['a', 'b', 'c']
join(iterable) 리스트를 합쳐 문자열 생성 'sep'.join(list) "-".join(['010', '1234']) '010-1234'
strip() 좌우 공백 제거 s.strip() " hello ".strip() 'hello'

f-string (문자열 서식 지정)

가장 권장되는 최신 포맷팅 방식입니다.

  • 문법: f'내용 {변수:서식}'
name = 'Adam'
print(f'Hello, {name:10s}!') # 결과: 'Hello, Adam      !' (10자리 확보)

3.3 Regular Expression (re 모듈)

특정 패턴을 가진 문자열을 검색하거나 치환할 때 사용합니다.

  • re.match(): 문자열 시작부터 패턴 일치 확인.
  • re.search(): 문자열 전체에서 패턴 일치 확인.
  • re.findall(): 패턴과 일치하는 모든 리스트 반환.
  • 예제:
import re
# 숫자가 1개 이상(+) 연속되는 패턴 찾기
result = re.findall('+', '123 abc 456')
print(result) # 결과: ['123', '456']

3.4 list & tuple

  • list: 가변(Mutable) 순서가 있는 집합. append(), pop(), sort() 등을 사용.
  • tuple: 불변(Immutable) 순서가 있는 집합. Unpacking(x, y = 1, 2)이 주요 기능입니다.
  • namedtuple: 컬럼에 이름을 부여하여 레코드처럼 사용.
from collections import namedtuple
City = namedtuple('City', 'name country')
seoul = City('Seoul', 'Korea')
print(seoul.name) # 결과: 'Seoul'

3.5 dict (사전)

키(Key)와 값(Value)의 쌍으로 저장하며, 키는 중복될 수 없습니다.

  • 문법: d = {key: value}
  • 주요 메서드:
    • get(key, default): 키가 없으면 에러 대신 기본값 반환.
    • update(dict2): 다른 사전을 병합하거나 수정.
  • 예제:
data = {1: "일", 2: "이"}
print(data.get(3, "알 수 없음")) # 결과: '알 수 없음'

4. 실무 보강: Comprehension & Collections

4.1 Comprehension (축약 표현)

반복 가능한 객체를 이용해 간결하게 새 컬렉션을 생성합니다.

  • 문법: [식 for 변수 in 시퀀스 if 조건]
  • 예제:
# 1~10 중 짝수만 제곱하여 리스트 생성
a = [n**2 for n in range(1, 11) if n % 2 == 0]
print(a) # 결과:

4.2 collections 모듈의 활용

  • deque: 양 끝에서 데이터 삽입/삭제 시 O(1)로 매우 빠릅니다. maxlen을 지정해 최근 데이터만 유지 가능합니다.
  • Counter: 요소의 개수를 세어주는 클래스.
from collections import Counter
c = Counter(['red', 'blue', 'red'])
print(c['red']) # 결과: 2
  • defaultdict: 키가 없을 때 기본값(예: 리스트)을 자동으로 생성해줍니다.

4.3 itertools 모듈 (조합 및 순열)

  • combinations(iterable, r): 조합(순서 상관X).
  • permutations(iterable, r): 순열(순서 상관O).
  • 예제:
from itertools import combinations
print(list(combinations(, 2))) # 결과: [(1, 2), (1, 3), (2, 3)]
