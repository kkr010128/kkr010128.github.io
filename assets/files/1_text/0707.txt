9) 연습문제
=>2부터 1000까지 완전수의 개수를 출력하는 문제
완전수는 자신을 제외한 약수의 합이 자기 자신인 수
6 의 약수는 1, 2, 3, 6인데 자신을 제외하고 1, 2, 3을 더하면 6이 되므로 6은 완전수

#개수를 저장할 변수
cnt = 0
for n in range(2, 1001):
    #약수의 합을 저장할 변수
    tot = 1
    #자신을 제외한 약수의 합
    for x in range(2, int(n/2)+1):
        if n % x == 0:
            tot = tot + x
    if tot == n:
        print(n)
        cnt = cnt + 1
print("완전수 개수:", cnt)

=>1년부터 2026년까지 윤년의 수
윤년의 조건
	4의 배수이고 100의 배수가 아닌 경우 윤년
	400의 배수인 경우 윤년

#윤년의 개수
cnt = 0
for n in range(1, 2027):
    if n % 4 == 0 and n % 100 != 0 or n % 400 == 0:
        cnt = cnt + 1

4.Function
1)개요
=>한 번에 실행되어야 하는 문장들을 하나의 이름으로 묶어서 독립적으로 실행할 수 있도록 한 것

=>함수의 이름만 호출하면 참조가 리턴되고 함수이름()은 함수의 호출(실행)

=>함수를 사용하는 경우의 장점
- 유지보수가 편리해짐
- 코드의 일정 부분을 논리적인 개념으로 분리할 수 있으므로 가독성이 높아짐
- 메모리 효율이 높아짐(함수를 호출하면 하나의 스택 메모리가 만들어지고 함수 내의 모든 내용은 스택에 저장해서 실행한 후 함수의 수행이 종료되면 스택이 소멸됩니다.)

=>함수의 종류
- built in function: 프로그래밍 언어나 프레임워크가 제공하는 함수

- user define function
3rd party function: 다른 개발자가 만들어준 함수

=>파이썬에서 함수는 일급 객체

=>return
- 함수의 수행을 종료하고 호출하는 곳으로 이동하는 제어문
- return 할 때 하나의 데이터를 가지고 리턴할 수 있습니다.
- 최근에는 함수의 리턴 타입을 적기도 합니다.

  [return 데이터]
- 리턴하지 않을 때는 자료형을 None으로 기재

=>Argument(매개변수)
- 함수를 호출하는 곳에서 함수에게 전달하는 데이터
- 초창기에는 이름만 기재했지만 최근에는 이름:자료형의 형태로 작성하는 경우가 많습니다.

- 매개변수에 Vector 데이터를 전달하면 데이터의 참조가 전달되는 형태로 함수 내부에서 데이터를 변경하면 원본 데이터가 변경될 수 있습니다.

=>매개변수의 unpacking
- 매개변수가 여러 개 일 때 데이터의 묶음으로 대입이 가능
- list, tuple, set의 경우는 *과 함께 대입하면 순서대로 매개변수에 대입이 됩니다.
- dict의 경우는 * 과 함께 대입하면 순서대로 매개변수에 대입이 됩니다.
dict의 경우는 ** 과 함께 대입하면 순서와 상관없이 key 와 매개변수의 이름을 매핑시켜서 대입합니다.

- **을 사용하면 하나의 dict로 묶어서 내부에서 사용됩니다.

#매개변수의 개수가 가변인 경우
def maxValue(*data):
    maxData = 0
    for imsi in data:
        if maxData < imsi:
            maxData = imsi
    return maxData

- 내부 함수에서 외부 함수의 데이터를 사용하고자 할 때는 global 대신에  nonlocal 사용
- closure: 함수안에서 함수를 리턴해서 함수 내부의 데이터를 외부에서 변경하고자 할 때 사용하는 문법
def outer():
    n = 0
    #함수 내부에 함수를 만들어서 외부 함수의 데이터를 변경하고 이 함수를 리턴하는 것을
    #closure 라고 합니다.
    def inner():
        nonlocal n
        n = n + 1
        print(n)
    return inner

=>데이터 처리와 관련된 함수
- map: 데이터를 변환해주는 함수
데이터 변환을 위한 함수 와 데이터 목록을 넘겨주면 데이터 목록의 데이터를 하나씩 함수에 대입해서 리턴받은 결과로 데이터 모임을 만들어주는 함수

대입해야 하는 함수는 하나의 매개변수를 받아서 리턴하는 함수이어야 합니다.

- filter: 데이터를 골라내는 함수
데이터 추출을 위한 함수 와 데이터 목록을 넘겨주면 데이터 목록의 데이터를 하나씩 함수에 대입해서 True를 리턴받은 데이터만 가지고 데이터 모임을 만들어 줍니다.

대입해야 하는 함수는 하나의 매개변수를 받아서 bool(True 나 False)를 리턴하는 함수이어야 합니다.

- reduce: 데이터를 가지고 연산하는 함수
기본 내장함수가 아님
functools 라는 패키지의 함수로 존재
2개의 매개변수를 가지고 데이터를 리턴하는 함수를 대입하면 되는데 첫번째 매개변수는 앞에서 수행한 함수의 결과
리턴하는 데이터는 마지막 연산을 수행한 결과 1개


ages = [23, 34, 41, 22, 33, 31, 27]
#나이에 해당하는 데이터를 1씩 증가시켜서 새로운 데이터 목록을 만들기
result = list(map(lambda x : x + 1, ages))
print(result)

#30이 넘는 데이터만 추출
result = list(filter(lambda x : x > 30, ages))
print(result)

from functools import reduce
#ages의 합계
result = reduce(lambda x, y: x+y, ages)
print(result)
