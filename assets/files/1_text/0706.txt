7.Data
0)Literal은 기본적으로 중복 저장되지 않으면 불변의 데이터입니다.

1)기본 데이터 종류
수치형 - int, float, complex -> Scala Type -> Immutable -> Direct로 접근

문자열(0개 이상의 글자) - str -> Vector(Container) -> Immutable -> Sequence로 접근 가능 
작은 따옴표나 큰 따옴표 안에 표기를 하고 여러 줄로 할 때는 세번씩

tuple -> 여러 종류의 데이터 모임(행으로 간주) ->Immutable -> Sequence
(데이터 나열...)

list -> 0개 이상의 데이터의 모임(의미상으로는 동일한 종류의 데이터 모임, 열) ->Mutable -> Sequence
bytes -> byte(영문 한 글자)의 모임 ->Immutable -> Sequence

dict -> 이름 과 값 쌍으로 저장하는 자료구조 -> Mutable -> Mapping
{"이름": 데이터, "이름", 데이터,...}

set -> 데이터를 중복없이 저장하는 자료구조 -> Mutable -> Set
{데이터, 데이터, 데이터 ...}

4)산술 비트 연산자
=>정수 데이터를 2진수로 변환해서 비트 단위로 연산을 수행 한 후 결과를 10진 정수로 리턴하는 연산자로 시스템 프로그래밍이나 데이터 분석 분야에서 많이 이용

=>&: AND 연산으로 둘 다 1일 때만 1
=>|: OR 연산. 둘 중 하나만 1이여도 1
=>^: XOR 연산. 두 개의 데이터가 다르면 1
=>~: 1의 보수 연산. (~a) = -61 → 1100 0011 
=><<: 왼쪽 시프트 연산자. 변수의 값을 왼쪽으로 지정된 비트 수 만큼 이동해주는 연산자로 한 번 이동할 때 마다 곱하기 2 한 효과
=>>>: 오른쪽 시프트 연산자. 변수의 값을 오른쪽으로 지정된 비트 수 만큼 이동해주는 연산자로 한 번 이동할 때마다 나누기 2한 효과
