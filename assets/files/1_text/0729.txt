16.File Sharing
4)NFS
=>구현 순서
- NFS 서버에 관련 패키지를 설치
- NFS 서버의 /etc/exports에 공유할 디렉토리, 접근을 허용할 컴퓨터, 접근 권한을 지정
- NFS 서비스를 실행

- NFS 클라이언트에 관련 패키지를 설치
- NFS 클라이언트에 showmount 명령을 실행해서 NFS 서버에 공유된 디렉토리가 있는지 확인
- NFS 클라이언트에서 mount 명령을 실행해서 NFS 서버에 공유된 디렉토리를 마운트

=>구현
- 서버
패키지 정보 업데이트: sudo apt update
관련 패키지 설치: sudo apt install nfs-kernel-server

공유할 디렉토리를 생성하고 접근 권한을 설정: sudo mkdir /share && sudo chmod 777 /share
공유 디렉토리에 파일 생성: sudo touch /share/file

설정 파일에 추가: sudo nano /etc/exports
/share 192.168.0.0/24(rw,sync,no_subtree_check,no_root_squash,insecure)
설정 내용 반영: sudo exportfs -rav

방화벽 설정: sudo ufw allow from 192.168.0.0/24

nfs-server가 부팅을 할 때 바로 시작: sudo systemctl enable nfs-server
nfs-server 재시작: sudo systemctl restart nfs-server
서비스 확인: sudo systemctl status nfs-server

- 클라이언트
관련 패키지 설치: sudo apt install nfs-common

NFS 서버에 공유된 디렉토리 확인: showmount -e 192.168.0.101

마운트 할 디렉토리 생성: mkdir ~/myshare

마운트: sudo mount -t nfs -o nfsvers=3 192.168.0.101:/share ~/myshare

17.Proxy Server
1)개요
=>프록시 서버는 클라이언트와 서버 사이에서 데이터를 중개하는 대리인 역할을 수행하는 서버로 사용자가 다른 곳과 통신을 하고자 할 때 직접 접속하는 대신 프록시 서버가 사용자의 요청을 받아서 전달하고 다시 사용자에게 보내주는 방식으로 동작하는 서버

=>기본 동작 원리
- 요청: 클라이언트가 다른 곳과 통신을 하고자 할 때 요청을 프록시 서버로 전송
- 중개: 프록시 서버는 클라이언트 대신 목적지 서버에 데이터를 요청
- 응답: 목적지 서버에서 보낸 응답을 프록시 서버가 받은 후 이를 다시 클라이언트에게 전송

2)사용 목적 및 특징
=>익명성 및 보안(Privacy & Security)
- IP 주소 숨김: 목적지 서버는 클라이언트의 실제 IP가 아닌 프록시 서버의 IP 알수 있기 때문에 사용자의 신원을 보호
- 방화벽 역할: 외부의 직접적인 공격으로부터 내부 네트워크를 보호하고 위험한 사이트로의 접근을 사전에 차단할 수 있음

=>성능 향상
- Caching: 자주 방문하는 곳의 데이터를 프록시 서버에 임시로 저장해두고 동일한 요청이 들어오면 서버까지 가지 않고 저장된 데이터를 즉시 반환해서 속도를 높이고 대역폭을 절약

=>접근 제어 및 필터링
- 유해 사이트 차단
- 특정 지역에서만 접근 가능한 콘텐츠를 우회해서 접속할 때 사용(VPN을 이용하는 경우가 많음)

=>종류
Forward Proxy: 클라이언트 앞에 위치를 해서 서버로 가는 요청을 가로채며 목적은 보안, 익명성, 내부망에서 외부 접속 관리 등

Reverse Proxy: 서버 앞에 위치하여 클라이언트의 요청을 서버로 분산하는데 목적은 로드 밸런싱, 서버 보안, SSL 암호화 처리 등

3)설치 및 구현
=>서버
- 패키지 설치: sudo apt -y install squid

- 설정 파일 수정: sudo nano /etc/squid/squid.conf
acl myserver src 192.168.0.0/24
http_access allow myserver
cache_dir ufs /var/spool/squid 1000 16 256

- 방화벽 중지: sudo ufw disable

https_proxy="http://192.168.0.101:3128/"
ftp_proxy="http://192.168.0.101:3128/"
no_proxy="localhost,127.0.0.1,localaddress"
HTTP_PROXY="http://192.168.0.101:3128/"
HTTPS_PROXY="http://192.168.0.101:3128/"
FTP_PROXY="http://192.168.0.101:3128/"
NO_PROXY="localhost,127.0.0.1,localaddress"

- 변경 내용을 적용: source /etc/environment

- apt에 적용할 설정 파일을 생성하고 작성: sudo nano /etc/apt/apt.conf.d/99proxy

Acquire::https::Proxy "http://192.168.0.101:3128/";

18.Shell Programming
1)개요
=>Shell Script는 Unix 나 Linux 또는 POSIX(Portable Operation System Interface)를 지원하는 운영체제인 Mac OS 등에서 일반적으로 사용되는 명려어 들과 if 나 for 같은 프로그래밍 적인 요소로 이루어진 인터프리터 기반의 스크립트 언어 
=>리눅스나 유닉스가 설치되어 있는 곳이라면 어디서든 실행이 가능
=>셸 스크립트오 프로그래밍 언어와 비슷하게 변수, 반복문, 제어문 등을 사용할 수 있음

=>작성
- 확장자는 생략하거나 직접 정해서 사용해도 되지만 관례상 sh를 사용
- 파일 내부에서는 상단에 #!/bin/bash 형태로 shebang을 작성해서 스크립트 파일이라는 것을 알려줍니다.
- 작성: name.sh
#!/bin/bash
echo "사용자 이름: " $USER
echo "홈 디렉토리: " $HOME
exit 0

=>실행
- sh 명령으로 실행: sh 파일경로

- 실행 가능한 속성으로 변경해서 실행
chmod +x name.sh

- 스크립트를 만들지 않고 실행
echo "사용자 이름: " $USER; echo "홈 디렉토리: " $HOME
 
2)변수
=>개요
- 변수를 사용하기 전에 미리 선언할 필요가 없습니다.
- 처음 변수에 값을 할당하면 자동으로 변수가 생성
- 변수 이름은 대소문자 구분을 하는데 대문자로 사용하는 경우가 많음
- 변수에 값을 대입할 때 = 다음에 공백을 두면 안됨
- 변수 타입은 필요하지 않으면 문자열을 저장하면 문자열이 저장되고 숫자를 저장하면 숫자가 저장됨
- 문자열 사이에 공백이 있을 때는 " "로 묶어야 함

=>변수 선언
- 변수를 사용을 할 때는 앞에 $를 붙여야 합니다.
- 변수 출력(echo)

=>산술 연산
- 변수에 넣은 값은 모두 문자열로 취급
- 산술 연산을 수행하려면 expr 이라는 키워드를 사용해야 하고 `(백틱)으로 묶어주어야 합니다.
- 수식에 괄호를 사용하고자 하는 경우 앞에 \를 추가해야 하비다.
- 곱하기(*)는 앞에 \를 추가해야 합니다.

=>위치 매개변수
- $숫자 형태를 갖습니다.
- 예를 들면 sh variable.sh -a --b
$0 이 variable.sh
$1 이 -a
$2 가 --b
- $*: 전체 인자를 의미하는데 -a --b
- $@: 전체 인자값인데 ""로 변수를 감싸면 다른 결과
- $#: 매개변수의 총 개수

3)함수
=>개요
- 특정 동작이나 목적을 위해 만들어진 코드의 묶음
- 사용하는 이유는 코드의 재사용
- function이라는 단어로 시작하고 함수 이름을 설정한 후 ( )를 하고 { }에 내용을 사용
- 문자열을 출력해주는 함수 활용: func.sh
#!/bin/bash

function print(){
        echo "Hello"
}

print

실행하고자 할 때 sh func.sh 는 에러가 발생: bash 명령으로 가능

실행 권한을 부여해서 실행을 하면 실행 가능

=>전역 변수 와 지역 변수
- 전역 변수: 함수 외부에서 생성해서 모든 곳에서 사용 가능한 변수
- 지역 변수: 함수 내부에서 local 이라는 단어와 함께 생성해서 함수 내부에서만 사용가능한 변수

=>특수 매개변수
- 현재 실행 중인 스크립트나 명령어의 프로세스 ID를 확인하거나 앞에서 실행한 명령어나 함수 또는 스크립트 실행이 정상적으로 수행되었는지 여부를 확인할 수 있는 변수
- $$: 현재 스크립트 또는 명령어의 PID
- $?: 최근에 실행된 명령어나 함수, 스크립트의 종료 상태
- $!: 최근에 실행된 백그라운드 명령의 PID
- $-: 현재 옵션 플래스

=>변수 확장
- 변수 와 문자열을 연속해서 사용할 때는 변수를 { }로 감싸야 합니다.

- 변수 초기화를 위한 확장 변경자
값이 없는 경우 치환을 위한 확장자
:을 생략하고 ${var-default} 처럼 사용하면 변수가 선언은 되어있으나 빈 문자열("")일 때는 값이 있는 상태로 취급하는데 :을 붙이면 값이 없는 걸로 취급합니다.
			변수가 존재하지 않는 경우			변수가 존재하는 경우
${var:-default} -> 변수를 유지하면서 default 반환			원래 변수값 반환
${var:=default} -> 변수를 변경하고 default 반환			원래 변수값 반환
${var:?message} -> message 출력 후 스크립트 종료		원래 변수값 반환
${var:+alternative} -> 아무것도 반환하지 않음			alternative 값 반환

- 문자열 추출 및 길이 확인
var="HelloBash"
${$var}: 문자열의 길이 -> 9
${$var:offset}: 첫번째 글자부터 offset 까지 잘라냄 -> ${var:5}: "Bash" 
${$var:offset:length}: offset 위치부터 length 만큼 잘라냄 -> ${var:0:5}: "Hello" 
${$var:-length}: 뒤에서부터 length 만큼 잘라냄 -> ${var:-4}: "Bash" 

- 패턴 삭제 및 파일 경로 추출
특정 문자열이나 패턴을 매칭해서 삭제를 수행하기 때문에 파일 이름이나 확장자를 추출할 때 유용
var="/home/user/test.txt"

${var#pattern}: 앞에서부터 패턴과 가장 처음 일치하는 부분까지 삭제
${var#*/}: home/user/test.txt

${var##pattern}: 앞에서부터 패턴과 가장 늦게 일치하는 부분까지 삭제
${var##*/}: test.txt

${var%pattern}: 뒷부분부터 패턴과 가장 처음 일치하는 부분 제거(확장자 제거)
${var%.*}: /home/user/test

- 치환 및 대소문자 변환
var="apple_pie"

${var/pattern/string}: pattern과 처음 일치하는 부분을 string으로 변환
${var/apple/banana} -> banana_pie

${var//pattern/string}: pattern과 일치하는 부분 전부를 string으로 변환
${var//_/ } -> apple pie

${var^}: 첫 글자만 대문자로 변환
${var^} -> Apple_pie

${var^^}: 모두 대문자로 변환
${var^^} -> APPLE_PIE

${var,}: 첫 글자만 소문자로 변환
${var,} -> aPPLE_PIE

${var,,}: 모두 소문자로 변환
${var,} -> apple_pie

- 문자열 비교 연산
=, ==, !=
>, <를 사용할 때는 [[를 이용해야 합니다.

=>and 와 or 연산
- and

- or

[ 조건식 ] || [ 조건식 ]

*: 0번 이상 반복
lo*v -> l로 시작하고 o가 몇 번 나오든 상관없고 v가 다음에 나와야 함

+: 1번 이상 반복
lo*v -> l로 시작하고 o가 반드시 1 번 이상 나오고  v가 다음에 나와야 함

?: 0번 또는 1번

{숫자}: 정확히 숫자 만큼

{숫자,}: 숫자 이상 반복

{숫자1, 숫자2}: 최소 숫자1 번 최대 숫자2 번

=>문자열을 묶거나 범위를 한정
- [ ]: 묶는 것
[abc]: a, b, c 중 하나
[a-z]: 소문자
[a-zA-Z]: 영문자
[^0-9]: 숫자가 아닌

- 기타
\: 특수문자를 원래의 문자 의미대로 해석(\? -> ?)
\b: 단어 끝의 공백
\B: 라인 끝의 공백
\<: 단어 시작에서 공백
\>: eksdj Rmxdptj rhdqor
