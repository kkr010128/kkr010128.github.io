1)coroutine
=>개요
- Generator의 특별한 형태
- yield로 값을 받아올 수 있음
- coroutine을 호출할 때는 send 라는 메서드를 이용하면 되는데 yield를 만날때 까지 수행하고 대기
def tot_coroutine():
    tot = 0
    while True:
        #next를 호출하면 이 자리에서 대기하고 있다가 send를 호출하면 데이터를 받아서 수행하고
        #다시 이 자리에서 대기
        data = (yield)
        tot = tot + data
        print("현재까지 합계:", tot)

#코루틴을 변수에 담기
co = tot_coroutine()

#맨 처음 한 번 호출
next(co)

#코루틴 수행
co.send(1)
co.send(2)

=>yield 다음에 변수를 만들면 next 와 send 메서드를 호출할 때 변수의 값을 리턴
=>coroutine을 종료하고자 하면 close를 호출하면 되는데 GeneratorExit 예외가 발생하는데 이 예외를 처리하면 coroutine의 종료 시점을 알 수 있음

key는 함수를 대입하는데 기존 데이터를 변환해주는 함수를 설정하는데 그 함수의 리턴값을 가지고 정렬을 수행

class Person:
    def __init__(self, num=0, name=""):
        self.num = num
        self.name = name

    def getNum(self):
        return self.num

    def getName(self):
        return self.name
    #< 연산자를 오버로딩, 크기 비교가 가능하게 해서 정렬이 되도록 합니다.
    def __lt__(self, other):
        return self.num < other.num

    def __str__(self):
        return self.num + ":" + self.name

person1 = Person(1, "park")
person2 = Person(2, "jesicca")
li = [person1, person2]

names = ["Park", "adam", "rusia", "RYU"]

names.sort()
print(names)
#내림차순 정렬
names.sort(reverse=True)
print(names)
#대소문자 구분하지 않고 정렬
#데이터에 함수를 적용해서 나온 결과를 가지고 정렬
names.sort(key=str.upper)
print(names)
#인스턴스들의 list 정렬은 특정한 값 하나를 리턴하는 함수를 이용

5)Comprehension
=>개요
- 반복 가능한 객체들을 이용해서 새로운 반복 가능한 객체를 축약한 형태로 생성하는 방법
- list, tuple, set, dict 등을 이용
- 반복 가능한 객체들을 간소화하게 되면 코드 구성이 깔끔해서 더 읽기 쉬운 코드가 만들어짐 

=>1부터 10까지의 list를 가지고 각각의 데이터를 제곱해서 list를 생성
#1부터 10까지의 숫자를 가지고 리스트 생성
l = list(range(1, 11))
#print(l)

#일반적인 방식
result = []
for i in l:
    result.append(i ** 2)
print(result)

#Comprehension 이용
result = [i**2 for i in l]
print(result)

=>for 다음에 if를 이용해서 조건에 맞는 데이터만 가지고 작업이 가능
#1부터 10까지의 list에서 짝수를 가지고 각각의 데이터를 제곱해서 list를 생성
result = [i**2 for i in range(1, 11) if i % 2 == 0]
print(result)

=>2개의 시퀀스를 사용하는 것도 가능
#앞의 배열에서 첫번째 데이터를 꺼내서 뒤의 배열 전체와 연산을 수행하고 다시 앞의 배열에서 두번째 데이터를 꺼내서 뒤의 데이터 전체와 연산
result = [i+j for i in range(1, 11) for j in range(101, 111)]
print(result)

=>이차원 배열 활용
l = [[1, 2, 3], [4, 5, 6]]
#이차원 배열을 일차원 배열로 변환
result = [j for i in l for j in i]
print(result)

=>조건에 따라 다른 작업을 수행해서 생성
#1부터 10까지의 숫자에서 짝수이면 제곱을 하고 홀수이면 그대로
result = [i*i if i % 2 ==0 else i for i in range(1,11)]
print(result)

data = [

7.Exception Handling
1)오류
=>오류의 종류
- 컴파일 에러: 문법적인 오류로 인해서 실행이 되지 않는 경우
- 논리적 에러: 에러가 발생하지는 않지만 알고리즘의 오류로 인해 잘못된 결과가 만들어지는 경우
- exception(예외): 문법적인 에러는 없어서 실행이 되지만 외부 요인이나 잘못된 입력 등으로 실행 도중 중지되는 경우
- assertion(단언): 의도적으로 예외를 발생시키는 것

=>오류 발생 시 조치
- 컴파일 에러가 발생하면 에러를 수정해서 실행: 컴파일 오류는 대다수의 IDE가 표시를 해주기 때문에 비교적 찾기 쉬움
- 논리적 에러나 예외는 디버깅을 통해서 메모리를 확인해나가면서 수정하거나 예외처리 구문을 추가

2)Exception(예외)
=>문법적으로는 이상이 없어서 컴파일 시점에는 아무런 문제가 없지만 프로그램 실행 도중에 발생하는 예기치 않은 사건으로 프로그램이 중단되는 현상

=>예외가 발생하는 경우 
- 정수를 0으로 나누는 경우
- 파일을 읽고자 하는데 파일이 없는 경우
- 통신을 하고자 하는데 상대방이 접속되지 않은 경우

=>예외 처리는 예외가 발생했을 때 수행될 작업을 작성하는 것

=>예외 처리의 목적
- 정상 종료
외부 자원을 사용하는 경우 예외가 발생하면 정상적으로 자원을 반납하고 종료하도록 작성

- 예외 내용을 기록
다음에 이러한 예외가 발생하지 않도록 하기 위해서

- 무시하고 계속 실행
예외가 그리 치명직이지 않아서 무시하고 실행

- 값을 변경해서 정상적으로 수행
비정상적인 값이 입력되는 경우 정상적인 값으로 변경해서 수행

=>기본적인 예외 처리
try:
	예외가  발생할 가능성이 있는 문장
except:
	예외가 발생했을 때 처리할 문장

#하나의 숫자를 입력받아서 10 나눈 결과를 출력하기
try:
    x = int(input("나눌 숫자를 입력하세요:"))
    y = 10 / x
    print(y)
except:
    print("예외가 발생했습니다.")

=>except 다음에 예외 종류를 설정해서 특정 예외만 처리할 수 있으며 여러 개의 except를 만들 수 있습니다.
여러 개의 except를 만드는 경우 상위 클래스의 except 클래스를 위에 작성하면 안됩니다.
객체 지향 프로그래밍에서는 상위 클래스 타입의 변수에 하위 클래스 타입의 인스턴스를 대입할 수 있습니다.
상단에 상위 클래스 타입의 예외를 처리하는 클래스를 두게되면 위에서 처리하기 때문에 아래 구문은 Dead Code가 됩니다.
파이썬에서 예외처리의 최상위 클래스는 BaseException -> Exception -> 기타 예외처리 클래스

#하나의 숫자를 입력받아서 10 나눈 결과를 출력하기
try:
    x = int(input("나눌 숫자를 입력하세요:"))
    y = 10 / x
    print(y)
#예외의 상위 클래스를 위에 작성하면 상위 클래스 예외 처리 구문이 동작합니다.
#아래 2개의 예외 처리 구문은 절대로 실행될 수 없는 Dead Code
except Exception:
    print("위 2개가 아닌 예외가 발생했습니다.")
except ValueError:
    print("정수로 바꿀 수 없는 데이터를 입력했습니다.")
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다")

=>else 와 finally
- try 다음에 else 블럭을 추가하면 예외가 발생하지 않은 경우 수행될 코드를 작성할 수 있습니다.

- try 다음에 finally 블럭을 추가하면 예외 발생 여부와 상관없이 수행될 문장을 작성할 수 있습니다.

except ZeroDivisionError:
    print("0으로 나눌 수 없습니다")
else:
    print("예외가 발생하지 않은 경우 수행할 문장")
finally:
    print("무조건 수행할 문장")

=>log.txt 파일을 읽어서 IP 별 트래픽의 합계를 구하시오
result = {}
try:
    f = open("./log.txt")
    for line in f:
        try:
            #한 줄을 읽어서 공백을 기준으로 분리
            data = line.split(" ")
            #첫번째 데이터 와 마지막 데이터를 저장
            ip = data[0]
            traffic = int(data[-1])
        except:
            traffic = 0
        #dict에 ip가 없으면 트래픽을 traffic으로 설정
        #dict에 ip가 있으면 그 때의 가져와서 새로 읽어 온 값을 더해줍니다.
        if ip not in result:
            result[ip] = traffic
        else:
            result[ip] = result[ip] + traffic
        
except:
    print("파일 경로가 잘못되었습니다.")

for ip, t in result.items():
    print(ip, t)
