=>kubernetes 클러스터에 배포하기 위한 manifest
- namespace를 생성하는 매니페스트: manifest/ns.yaml
apiVersion: v1
kind: Namespace
metadata:
  name: bgd

- deployment를 생성하는 매니페스트: manifest/deployment.yaml
---
apiVersion: apps/v1
kind: Deployment
metadata:
  labels:
    app: bgd
  name: bgd
  namespace: bgd
spec:
  replicas: 1
  selector:
    matchLabels:
      app: bgd
  strategy: {}
  template:
    metadata:
      creattionTimestamp: null
      labels:
        app: bgd
    spec:
      containers:
      - image: ggnagpae1/bgd:1.0.0
        name: bgd
        env:
        - name: COLOR
          value: "blue"
        resources: {}
---

- service를 생성하는 매니페스트: manifest/svc.yaml
---
apiVersion: v1
kind: Service
metadata:
  labels:
    app: bgd
  name: bgd
  namespace: bgd
spec:
  ports:
  - port: 8080
    protocol: TCP
    targetPort: 8080
    nodePort: 31080
  selector:
    app: bgd
  type: NodePort
---

=>git hub에 push

=>argocd 배포
- 파일 생성(argocd가 설치된 운영체제에서 작업): bgd-app.yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: bgd-app
  namespace: argocd
spec:
  destination:
    namespace: bgd
    server: https://kubernetes.default.svc
  project: default
  source:
    repoURL: https://github.com/itstudy001/bgd.git
    path: manifest
    targetRevision: main

- 파일 배포: kubectl apply -f bgd-app.yaml

- Argocd는 기본적으로 애플리케이션을 자동으로 동기화하지 않고 생겼음을 알려줄 뿐
- 맨 처음 한 번은 수동으로 동기화를 수행

- argocd app sync bgd-app
