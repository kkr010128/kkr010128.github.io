11)pipeline 
=>개요
- 연속적인 이벤트 혹은 Job의 그룹
- 순차적 혹은 병렬적으로 실행시키거나 특별하게 작성한 스크립트로 이벤트들을 연속적으로 실행시키는 등의 일을 지원하는 기능
- jenkins pipeline은 Jenkins를 사용해서 연속적인 전달 파이프라인의 통합 및 구현을 지원하는 플러그인의 집합
- 파이프라인은 파이프라인 DSL을 통해 간단하거나 복잡한 전달 파이프라인을 코드로 생성할 수 있는 확장 가능한 자동화 서버를 갖추고 있음

=>빌드 후 조치를 이용한 다른 프로젝트 빌드
- 프로젝트에서 [빌드 후 조치 추가]를 선택한 후 Build other projects 메뉴가 있는데 이를 선택하면 빌드가 끝난 후 다른 프로젝트를 실행하는 것이 가능

=>Pipeline 시각화 작업
- 플로그 인 설치: Delivery Pipeline

- 프로젝트 보기 화면에서 All 옆의 + 버튼을 눌러서 새로운 뷰를 생성

=>작성 방법
- Declarative
- Scripted(Groovy + DSL(도메인 특화 언어 - 도메인에만 적용되는 특별한 언어))

=>작성 방법의 차이점
- 특정 stage 실행 가능 여부: Declarative 방식은 작업이 실패하면 다음 작업을 수행하지 못하지만 Scripted 방식은 다음 작업 수행이 가능
- Scripted 방식은 제어문 사용 가능
- Scripted 방식은 Pipeline으로 시작하고 Declarative 방식은 node로 시작

pipeline{
    agent any
    environment{
        DOCKER_CREDENTIALS_ID = 'dockerhub'
    }
    stages{
        stage('github clone'){
            steps{
                git branch:'main', url:'https://github.com/example-org/calculator.git'
            }
        }
         stage('permission'){
            steps{
                sh "chmod +x ./gradlew"
            }
        }
        stage('Build'){
            steps{
                sh "./gradlew clean build --stacktrace"
            }
        }
        stage('Image Build'){
            steps{
                sh "docker build -t example-user/calculator ."
            }
        }
        stage('Docker Login'){
            steps{
                script{
                    withCredentials([usernamePassword(credentialsId:env.DOCKER_CREDENTIALS_ID, usernameVariable: 'DOCKER_USERNAME', passwordVariable:'DOCKER_PASSWORD')]){
                        sh 'echo $DOCKER_PASSWORD | docker login -u $DOCKER_USERNAME --password-stdin'
                    }
                }
            }
        }
    }
}

=>Docker가 설치된 SSH 서버를 준비
- jenkins가 설치된 곳에서 ssh-keygen -t rsa -b 4096 명령어로 private 키 와 public key를 생성
- jenkins에는 Publish Over SSH 와 SSH Agent 플러그인을 설치
- jenkins에 SSH username with private key를 선택해서 ID, username, private key를 설정합니다.
Passphrase 옵션은 키를 생성할 때 비밀번호를 설정했으면 입력하고 없으면 비워둠

  echo "이미지 $IMAGE_NAME 삭제 중..."
  docker rmi -f "$IMAGE_NAME:$TAG"
fi

#컨테이너도 삭제
docker ps -q -f name=calculator | grep -q . && sudo docker stop calculator

#새로운 이미지 다운로드

docker pull "$IMAGE_NAME:$TAG"

docker run -d -p 외부포트:내부포트 --rm --name calculator "$IMAGE_NAME:$TAG"
docker image prune -f
