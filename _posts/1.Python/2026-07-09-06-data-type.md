## 1) Sequence Type
---
### str (문자열)
- Immutable, Sequence 접근 가능
- 작은따옴표나 큰따옴표 사용, 여러 줄은 `""" """`

### list (리스트)
- **Mutable**, Sequence
- 0개 이상의 데이터 모임 (의미상 동일한 종류)

### tuple (튜플)
- **Immutable**, Sequence
- 여러 종류의 데이터 모임 (행으로 간주)
- `(데이터 나열...)`

### dict (딕셔너리)
- **Mutable**, Mapping
- `{"이름": 데이터, ...}` 형태의 Key-Value 쌍

### set (세트)
- **Mutable**, Set
- 데이터를 중복 없이 저장
- `{데이터, ...}`

### bytes
- **Immutable**, Sequence
- byte(영문 한 글자)의 모임

## 2) Comprehension
---
### List Comprehension
```python
[표현식 for 임시변수 in iterable]
[표현식 for 임시변수 in iterable if 조건]

# 예시
[x * x for x in range(1, 11)]
[x for x in range(10) if x % 2 == 0]
```

### Dict Comprehension
```python
{키_표현식: 값_표현식 for 임시변수 in iterable}
```

### Set Comprehension
```python
{표현식 for 임시변수 in iterable}
```
