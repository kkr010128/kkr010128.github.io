## 1) 파일 처리 과정
---
1. 파일 열기 (`open`)
2. 데이터 읽기/쓰기
3. 파일 닫기 (`close`)

## 2) open
---
```python
변수 = open(파일경로, 모드)
```

### 모드

| 모드 | 설명 |
| ---- | ---- |
| `"r"` | 읽기 (기본) |
| `"w"` | 쓰기 (기존 내용 덮어씀) |
| `"a"` | 추가 (기존 내용 유지) |
| `"x"` | 새 파일 생성 (기존 파일 있으면 에러) |
| `"b"` | 바이너리 모드 (rb, wb) |

## 3) 파일 읽기
---
```python
f = open("file.txt", "r", encoding="utf-8")
content = f.read()          # 전체 읽기
line = f.readline()         # 한 줄 읽기
lines = f.readlines()       # 모든 줄을 리스트로
f.close()
```

## 4) 파일 쓰기
---
```python
f = open("file.txt", "w", encoding="utf-8")
f.write("내용\n")
f.close()
```

## 5) with 구문 (권장)
---
자동으로 파일 닫기 처리
```python
with open("file.txt", "r", encoding="utf-8") as f:
    content = f.read()
# 블록 벗어나면 자동 close
```
