## 1 ) 네트워크 보안의 5대 요소
---

#### 개요

네트워크 보안은 정보 자산을 안전하게 보호하기 위한 기본 원칙으로 다음 다섯 가지 요소로 구성된다.

- 기밀성(Confidentiality)
- 무결성(Integrity)
- 가용성(Availability)

위 세 가지를 **CIA 3대 요소**라고 하며, 여기에 다음 두 가지 인증 요소를 추가한다.

- 서버 인증(Server Authentication)
- 클라이언트 인증(Client Authentication)

---

### 기밀성 (Confidentiality)

#### 개요

기밀성은 인가되지 않은 사용자나 객체가 정보의 내용을 볼 수 없도록 보호하는 것이다.

#### 기밀성을 위한 인증 요소

사용자의 신원을 확인하기 위해 다음과 같은 인증 요소를 사용할 수 있다.

| 구분 | 설명 | 예시 |
|---|---|---|
| 소유 기반(Possession) | 사용자가 가지고 있는 것 | OTP, 보안 토큰 |
| 지식 기반(Knowledge) | 사용자가 알고 있는 것 | ID, Password |
| 생체 기반(Inherence) | 사용자의 신체적 특징 | 지문, 홍채, 얼굴 인식 |

#### 기밀성의 예

기밀성을 보장하기 위한 대표적인 예는 다음과 같다.

- 보안 관련 시스템 및 소프트웨어
- 방화벽(Firewall)
- 암호화
- Password

방화벽은 대표적으로 MAC Address나 IP Address 등을 확인하여 허가되지 않은 접근을 제한한다.

#### 네트워크 보안에서의 기밀성

다음과 같은 통신에서 허가되지 않은 사용자나 객체가 정보의 내용을 알 수 없도록 보호하는 것을 의미한다.

- 서버 ↔ 클라이언트
- 서버 ↔ 서버
- 클라이언트 ↔ 클라이언트

#### 기밀성을 해치는 공격

대표적인 공격은 Sniffing이다.

- Cookie Sniffing
- Traffic Sniffing
- Ethernet Sniffing

> **정리**
>
> - 기밀성은 허가되지 않은 사용자의 정보 열람을 방지하는 것이다.
> - 인증 요소는 소유, 지식, 생체 기반으로 구분할 수 있다.
> - 네트워크에서 기밀성을 해치는 대표적인 공격은 Sniffing이다.

---

### 무결성 (Integrity)

#### 개요

무결성은 인가된 사용자만 데이터에 접근하고 수정할 수 있으며, 데이터가 임의로 변경되지 않았음을 보장하는 것이다.

#### 예시

위조지폐는 원본의 내용이 변경된 것으로 무결성이 훼손된 대표적인 사례이다.

#### 네트워크 보안에서의 무결성

클라이언트와 서버 사이에서 전송되는 데이터가 중간에서 변조되지 않고 그대로 전달되는 것을 의미한다.

#### 무결성을 해치는 공격

대표적인 공격은 Session Hijacking이다.

Session Hijacking은 정상 사용자의 세션을 탈취하여 해당 사용자의 권한으로 서비스를 이용하는 공격이다.

> **정리**
>
> - 무결성은 데이터가 변경되지 않았음을 보장한다.
> - 위조지폐는 무결성이 훼손된 대표적인 예이다.
> - 네트워크에서 무결성을 해치는 대표적인 공격은 Session Hijacking이다.

---

### 가용성 (Availability)

#### 개요

가용성은 필요한 순간에 정보 자산에 접근하여 서비스를 정상적으로 사용할 수 있도록 보장하는 것이다.

#### 예시

24시간 운영되는 편의점은 사용자가 필요한 시간에 언제든지 이용할 수 있다는 점에서 가용성의 대표적인 예이다.

#### 네트워크 보안에서의 가용성

허가된 사용자나 객체가 네트워크를 통해 정보나 서비스에 접근하려고 할 때 방해받지 않도록 하는 것을 의미한다.

#### 가용성을 해치는 공격

대표적인 공격은 DoS(Denial of Service)이다.

DoS는 서비스 거부 공격으로, 정상 사용자가 서비스를 이용하지 못하도록 만드는 공격이다.

> **정리**
>
> - 가용성은 필요한 시점에 정보와 서비스를 사용할 수 있도록 보장하는 것이다.
> - 24시간 편의점은 가용성의 대표적인 예이다.
> - 네트워크에서 가용성을 해치는 대표적인 공격은 DoS이다.

---

### 서버 인증 (Server Authentication)

#### 개요

서버 인증은 클라이언트가 접속한 서버가 올바른 서버인지 확인하는 과정이다.

즉, 클라이언트가 서버에 접근할 때 서버의 신원을 확인하기 위한 인증이다.

#### 특징

- HTTPS(SSL/TLS), SSH 등에서 서버 인증을 수행한다.
- 인증서를 이용하여 서버의 신뢰성을 확인한다.
- 인증서에 문제가 있으면 브라우저는 경고를 표시하고 사용자에게 접속 여부를 선택하도록 한다.
- 현재는 강제적인 서버 인증보다 사용자의 선택에 맡기는 방식이 일반적이다.

> **정리**
>
> - 서버 인증은 클라이언트가 올바른 서버에 접속했는지 확인하는 과정이다.
> - HTTPS와 SSH에서 대표적으로 사용된다.
> - 인증서에 문제가 있으면 사용자에게 경고를 표시한다.

---

### 클라이언트 인증 (Client Authentication)

#### 개요

클라이언트 인증은 서버가 접속을 시도하는 사용자가 정상적인 클라이언트인지 확인하는 과정이다.

#### 대표적인 인증 방법

- ID / Password
- OTP
- 인증서
- 생체 인증

웹 사이트에 로그인할 때 사용하는 ID와 Password가 가장 대표적인 클라이언트 인증 방법이다.

#### 클라이언트 인증과 관련된 공격

- Spoofing
- Session Hijacking
- Phishing

> **정리**
>
> - 클라이언트 인증은 서버가 사용자의 신원을 확인하는 과정이다.
> - ID와 Password가 가장 대표적인 인증 방법이다.
> - 대표적인 관련 공격은 Spoofing, Session Hijacking, Phishing이다.

---

### 최종 정리

| 요소 | 목적 | 대표적인 위협 |
|---|---|---|
| 기밀성 | 정보의 노출 방지 | Sniffing |
| 무결성 | 데이터 변조 방지 | Session Hijacking |
| 가용성 | 서비스의 지속적인 제공 | DoS |
| 서버 인증 | 서버의 신원 확인 | 위조 서버 |
| 클라이언트 인증 | 사용자의 신원 확인 | Spoofing, Session Hijacking, Phishing |

> **정리**
>
> - 네트워크 보안은 CIA 3대 요소와 서버·클라이언트 인증으로 구성된다.
> - 기밀성은 정보 노출, 무결성은 데이터 변조, 가용성은 서비스 중단과 관련된다.
> - 서버 인증은 서버의 신원을, 클라이언트 인증은 사용자의 신원을 확인하기 위한 과정이다.
