## 1. INSERT (데이터 삽입)

- **정의**: 테이블에 새로운 행(Row)을 추가하는 명령어임.
- **특징**:
    - `INTO` 키워드는 생략 가능함.
    - 필드 목록을 생략할 경우, 테이블 구조에 정의된 모든 컬럼의 값을 순서대로 입력해야 함.

### 1.1 기본 문법 및 예제

```sql
-- 필드 목록 명시
INSERT INTO tCity (name, area, popu, metro, region)
VALUES ('평택', 453, 51, 'n', '경기');

-- 필드 목록 생략 (전체 값 입력)
INSERT INTO tCity VALUES ('서울', 605, 974, 'y', '경기');
```

### 1.2 확장 INSERT (다중 삽입)

- `VALUES` 절 뒤에 여러 개의 데이터 셋을 쉼표(`,`)로 구분하여 나열하면 한 번의 명령으로 여러 행을 동시에 삽입할 수 있음.
- **예제**:

```sql
INSERT INTO tCity (name, area, popu, metro, region) VALUES
('부산', 765, 342, 'y', '경상'),
('오산', 42, 21, 'n', '경기'),
('청주', 940, 83, 'n', '충청');
```

### 1.3 INSERT SELECT (데이터 복사)

- 다른 테이블의 조회 결과(Result Set)를 대상 테이블에 그대로 삽입할 때 사용함.
- **예제**: tCity에서 경기 지역 데이터만 뽑아 tStaff에 삽입함.

```sql
INSERT INTO tStaff(name, depart, gender, joindate, grade, salary, score)
SELECT name, region, metro, '20210629', '신입', area, popu
FROM tCity
WHERE region = '경기';
```

### 1.4 CREATE TABLE AS SELECT (CTAS)

- 테이블 생성과 동시에 조회 데이터를 삽입하는 방법임.
- **예제**: 경기 지역 도시 정보만 가진 `tSudo` 테이블 생성함.

```sql
CREATE TABLE tSudo AS
SELECT name, area, popu
FROM tCity
WHERE region = '경기';
```

## 2. 조건부 삽입 (INSERT IGNORE)

- **설명**: 중복 키 에러 등이 발생할 경우 작업을 중단하지 않고, 에러가 발생한 행만 무시한 뒤 다음 스크립트를 계속 수행함.
- **예제**:

```sql
-- 동일한 PK(karina)가 있어도 에러 없이 다음 명령 수행함
INSERT IGNORE INTO memberTBL VALUES('karina', '카리나', '수원');
INSERT IGNORE INTO memberTBL VALUES('aeri', '지젤', '서울');
```

## 3. UPDATE (데이터 수정)

- **정의**: 테이블에 이미 저장된 데이터를 변경하는 명령어임.
- **주의**: `WHERE` 절을 생략하면 테이블 내의 **모든 데이터**가 수정되므로 주의해야 함.

### 3.1 기본 문법 및 예제

```sql
-- 특정 행의 여러 컬럼 수정
UPDATE tCity
SET popu = 1000, region = '충청'
WHERE name = '서울';

-- 모든 데이터 일괄 수정
UPDATE tCity SET popu = 1000, region = '충청';
```

### 3.2 산술 연산자를 이용한 갱신

- 기존 값에 연산을 수행하여 업데이트할 수 있음.
- **예제**: 오산의 인구수를 2배로 늘림.

```sql
UPDATE tCity
SET popu = popu * 2
WHERE name = '오산';
```

## 4. DELETE (데이터 삭제)

- **정의**: 테이블의 행을 삭제하는 명령어임.
- **특징**: `WHERE` 절이 없으면 테이블의 모든 행이 삭제되지만, 테이블 구조 자체는 남아있음.

### 4.1 기본 문법 및 예제

```sql
-- 특정 데이터 삭제
DELETE FROM tCity WHERE name = '부산';

-- 조건에 맞는 데이터 일괄 삭제
DELETE FROM tCity WHERE region = '경기';

-- 전체 데이터 삭제
DELETE FROM tCity;
```

---

> [!warning] **DML 사용 시 주의사항**
> 
> - `UPDATE`와 `DELETE` 수행 전에는 반드시 `SELECT`문으로 대상 데이터를 먼저 확인하여 조건이 정확한지 검토해야 함.
> - 대량의 데이터를 삭제할 때는 로그를 남기는 `DELETE`보다 속도가 빠른 `TRUNCATE` 사용을 고려할 수 있음. (TCL 파일 내용 참고)
