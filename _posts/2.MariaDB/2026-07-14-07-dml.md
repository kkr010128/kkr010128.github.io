## 1) INSERT (데이터 삽입)
---
### 단일 행 삽입
```sql
INSERT INTO 테이블(컬럼1, 컬럼2) VALUES (값1, 값2);
```

### 다중 행 삽입
```sql
INSERT INTO 테이블(컬럼1, 컬럼2) VALUES (값1, 값2), (값3, 값4), (값5, 값6);
```

### 서브쿼리로 삽입
```sql
INSERT INTO 테이블 SELECT * FROM 다른테이블 WHERE 조건;
```

## 2) UPDATE (데이터 수정)
---
```sql
UPDATE 테이블 SET 컬럼1 = 값1, 컬럼2 = 값2 WHERE 조건;
```

> `WHERE` 절 생략 시 모든 행이 수정되므로 주의

## 3) DELETE (데이터 삭제)
---
```sql
DELETE FROM 테이블 WHERE 조건;    -- 특정 행 삭제
DELETE FROM 테이블;               -- 전체 행 삭제
```
