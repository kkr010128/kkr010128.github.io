## 1) SELECT 기본
---
### 형식
```sql
SELECT 컬럼명 FROM 테이블명;
SELECT * FROM 테이블명;        -- 전체 컬럼
```

### 컬럼 별명 (Alias)
```sql
SELECT name AS 이름, age AS 나이 FROM users;
```

### 계산식 출력
```sql
SELECT salary * 12 AS 연봉 FROM employees;
```

### CONCAT (문자열 결합)
```sql
SELECT CONCAT(first_name, ' ', last_name) AS full_name FROM employees;
```

### DISTINCT (중복 제거)
```sql
SELECT DISTINCT department FROM employees;
```

## 2) ORDER BY (정렬)
---
```sql
SELECT * FROM 테이블 ORDER BY 컬럼 ASC;    -- 오름차순 (기본)
SELECT * FROM 테이블 ORDER BY 컬럼 DESC;   -- 내림차순
SELECT * FROM 테이블 ORDER BY 컬럼1 ASC, 컬럼2 DESC;  -- 다중 정렬
```

## 3) WHERE 절
---
### 비교 연산자
```sql
=, <>, >, <, >=, <=
```

### 논리 연산자
```sql
AND, OR, NOT
```

### BETWEEN
```sql
WHERE age BETWEEN 20 AND 30
```

### IN
```sql
WHERE department IN ('Sales', 'IT')
```

### LIKE (패턴 검색)
```sql
WHERE name LIKE '김%';    -- 김으로 시작
WHERE name LIKE '%수';    -- 수로 끝남
WHERE name LIKE '%민%';   -- 민 포함
```

### IS NULL
```sql
WHERE email IS NULL;
WHERE email IS NOT NULL;
```

## 4) LIMIT
---
```sql
SELECT * FROM 테이블 LIMIT 10;          -- 10개만
SELECT * FROM 테이블 LIMIT 10 OFFSET 5; -- 6~15번째
SELECT * FROM 테이블 LIMIT 5, 10;       -- 6~15번째 (MySQL 호환)
```

## 5) 검색 결과 파일로 저장
---
```sql
SELECT * FROM 테이블 INTO OUTFILE '/경로/파일명.csv';
```
