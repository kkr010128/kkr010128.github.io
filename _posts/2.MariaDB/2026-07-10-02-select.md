## 1. 개요 및 주석

- **SELECT의 목적**: 데이터베이스에서 원하는 데이터를 추출하여 Result Set(결과 셋)을 만드는 것임.
- **주석 사용법**:
    - 한 줄 주석: `--` (반드시 뒤에 공백이 있어야 함).
    - 여러 줄 주석: `/* 내용 */`.

## 2. SQL SELECT의 연산

- **SELECTION**: 테이블에서 특정 행(Row)을 선택함.
- **PROJECTION**: 테이블에서 특정 열(Column)을 선택함.
- **JOIN**: 여러 테이블에 흩어져 있는 데이터를 링크를 통해 함께 가져옴.

---

## 3. SELECT 기본 문법 및 실행 순서

### 3.1 기본 형식

```sql
SELECT [DISTINCT] {*, 컬럼명 [Alias], ...}
FROM 테이블명
[WHERE 조건]
[GROUP BY 그룹조건]
[HAVING 그룹이후조건]
[ORDER BY 정렬기준 [ASC | DESC]]
[LIMIT 행_개수 [OFFSET 건너뛸_개수]];
```

### 3.2 실행 순서 (매우 중요)

1. **FROM**: 대상 테이블을 먼저 찾음.
2. **WHERE**: 대상 데이터 중 조건에 맞는 행을 필터링함.
3. **GROUP BY**: 데이터를 특정 기준에 따라 그룹화함.
4. **HAVING**: 그룹화된 데이터에 필터링 조건을 적용함.
5. **SELECT**: 출력할 컬럼을 결정함.
6. **ORDER BY**: 최종 결과의 정렬 순서를 정함.

## 4. 데이터 조회 실습

### 4.1 모든 열/특정 열 선택

- **전체 조회**: `*`를 사용함. 오라클과 달리 MariaDB는 데이터 입력 순서대로 조회되는 경향이 있음.
- **예제**: `SELECT * FROM tCity;`
- **특정 컬럼 조회**: 필요한 필드명만 나열함.
- **예제**: `SELECT name, salary FROM tStaff;`

### 4.2 필드 별명 (Alias)

- Result Set의 헤더 이름을 직관적으로 바꿀 때 사용함. `AS`를 쓰거나 한 칸 띄우고 작성함. 공백이 포함되면 큰따옴표(`""`)로 감싸야 함.
- **문법**: `컬럼명 AS "별명"`
- **예제**: `SELECT name 도시명, area AS "면적(제곱Km)" FROM tCity;`

### 4.3 산술 연산자

- 조회 시 데이터를 가공할 수 있음. `+`, `-`, `*`, `/`, `DIV`(몫), `%`, `MOD`(나머지) 지원함.
- **예제**: 인구수에 10000을 곱해 실제 명수 출력

```sql
SELECT name, popu * 10000 AS "인구(명)" FROM tCity;
```

## 5. 조건 필터링 (WHERE 절)

### 5.1 비교 및 논리 연산

- **논리 연산자**: `AND`, `OR`, `XOR`, `NOT` 사용함. `AND`가 `OR`보다 우선순위가 높음.
- **NULL 비교**: NULL은 `0`이나 빈 문자열과 다름. `IS NULL` 또는 `IS NOT NULL`을 사용해야 함.
- **대소문자 구분**: 기본적으로 구분하지 않으나, 컬럼 설정을 `utf8mb4_bin`으로 변경하면 구분 가능함.

```sql
ALTER TABLE tCity MODIFY metro VARCHAR(1) COLLATE utf8mb4_bin;
SELECT * FROM tCity WHERE metro = 'Y'; -- 대문자 Y만 조회됨
```

### 5.2 LIKE (와일드카드)

- **`%`**: 0개 이상의 문자.
- **`_`**: 정확히 1개의 문자.
- **예제**: '천'으로 끝나는 이름 조회: `SELECT * FROM tCity WHERE name LIKE '%천';`
- **특수문자 조회**: `%`나 `_` 자체를 검색할 때는 `ESCAPE` 문자를 정의함.
    - 예: `LIKE '%30#%' ESCAPE '#'` (30%가 포함된 데이터 조회)

### 5.3 IN 연산자

- 여러 값 중 하나라도 일치하면 참임. `OR`를 여러 번 쓰는 것보다 효율적임.
- **예제**: `SELECT * FROM tCity WHERE region IN ('경상', '전라');`

## 6. 정렬 및 행 제한

### 6.1 ORDER BY (정렬)

- **ASC**: 오름차순(기본값).
- **DESC**: 내림차순.
- **예제**: 경기 지역 도시를 면적순으로 정렬

```sql
SELECT * FROM tCity WHERE region = '경기' ORDER BY area;
```

### 6.2 LIMIT (행 개수 제한)

- 페이징 처리에 필수적인 문법임.
- **형식**: `LIMIT [건너뛸 개수], 조회할 개수`
- **예제**: 면적이 넓은 상위 4개 도시 조회

```sql
SELECT * FROM tCity ORDER BY area DESC LIMIT 4;
```

- **예제**: 3위부터 5위까지(2개 건너뛰고 3개) 조회

```sql
SELECT * FROM tCity ORDER BY area DESC LIMIT 2, 3;
-- 또는 OFFSET 사용
SELECT * FROM tCity ORDER BY area DESC LIMIT 3 OFFSET 2;
```

## 7. 결과 저장 (파일 출력)

- SELECT 결과를 외부 파일(`.dat`, `.csv` 등)로 내보낼 때 사용함.
- **주의**: 지정한 디렉토리가 미리 생성되어 있어야 함.
- **예제**: members 테이블 전체 데이터를 쉼표로 구분하여 저장

```sql
SELECT * INTO OUTFILE '/path/members.dat'
FIELDS TERMINATED BY ','
ENCLOSED BY '"'
FROM members;
```
