## 2 ) 명령어 구조
---
### command [option] [arg]
- option은 세부 기능
	- `-{opt}` 또는 `--{option}`로 시작
- `[ ]`은 생략 가능
- ` | `은 선택
- 문자열, `{ }, < >`는 필수

### 명령어 자동완성
- 현재 입력중인 내용으로 시작하는 명령어가 1개라면 `\t` → 자동완성
	- 2개 이상이라면 `\t \t`  → 모든 명령어 조회
### history
- 위•아래 방향키로 명령어 history 사용 가능
- 명령어를 입력 후 Ctrl  + R 입력 시
	→ 해당 명령어로 시작하는 이전 명령어 조회
	
- `!!` → 직전 명령 재실행
- `history` → 명령 사용 기록
	- `!{num]`→ 번호에 해당하는 명령 실행
	- `!{str}` → 문자열로 시작하는 마지막 실행 명령을 실행
	- `history -d {line_num}` → 명령어 삭제
	- `history -c` → 명령어 목록 모두 삭제
		→ 명령어 기록된 파일은 `home/.bash_history`
### Command Etc.
- `--help` 
	→ 사용 방법 및 옵션
- `echo $PATH`
	→ 명령어를 찾는 위치 - : 로 구분돼 있음
- `whereis`
	→ 명령어의 실행 파일 위치 및 소스 위치 등 확인
- `which`
	→ PATH env에 저장된 디렉토리에서 명령어의 위
- `exit`
	→ 터미널 종료
- `clear`
	→ 터미널 정리
	
### Alias
- `alias`
	→ 현재 설정된 별명 확인
	
- `alias {aka} = {cmd}`
- `type {aka}` → 별명인지 확인 가능
- `unalias` → 별명 삭제

### 원본 명령 수행
- 전체 경로로 명령어 입력
- `command {cmd}` 명령어로 수행
- `\{cmd}` 수행
### 시간 관련 명령
- `date`
	→ Ubuntu 시스템에서 설정돼있는 현재 시각과 날짜를 출력
- `timedatectl`
	→ 하드웨어 시계와 소프트웨어 시계, UTC, Timezone, 시간 동기화 등을 출력
	
- `timedatectl list-timezone`
	→ timezone 목록
- `sudo timedatectl set-timezone Asia/Seoul`
	→ timezone 변경
### 시스템 사용자 정보
- `logname, whoami`
	→ 현재 사용중인 사용자 확인
- `users, who`
	→ 현재 접속한 사용자 아이디를 전부 조회
- `uname [option]`
	→ 시스템 정보
	- `a`: 모든 정보 확인
	- `m`: 하드웨어 정보
	- `n`: 호스트 이름 확인
	- `r`: 운영체제 릴리즈 번호
	- `s`: 운영체제 이름
- `hostname`
	→ 현재 사용 중인 호스트 네임
	- `arch`: cpu 정보
	- `env`: 환경 변수
### sudo와 su
- `sudo {cmd}`
	→ 관리자의 권한을 빌려 명령을 실행함
- `su {user} {cmd}`
	→ 현재 계정의 환경 변수들을 유지하며 다른 계정으로 전환
- `su - {user} {cmd}`
	→ 새로운 계정의 환경 변수를 가져오며 계정 전환
- `su`
	→ root 계정으로 전환
	- root 계정의 비밀번호가 설정돼 있어야 함(passwd root)

## 4 ) 문서 편집기
1. 편집기 종류
	- 행 단위 편집기: `ed, ex, sed`
	- 화면 단위 편집기:` vi(vim), emacs, nano(메뉴기반)`
	- GUI 편집기: `gedit`
2. 모드형과 비모드형
	- 모드형 편집기
		- 입력 모드와 명령 모드가 구분돼 있음
		- 입력 모드는 텍스트를 입력하고 수정할 수 있는 모드
		- 명령 모드는 텍스트를 저장하거나 복붙같은 명령 수행하는 모드
		- vi가 대표적인 모드형 편집기

	- 비모드형 편집기
		- 입력 모드와 명령 모드가 구분되어 있지 않음
		- 편집 기능을 `Alt`나 `Ctrl` 같은 조합키와 사용
		- nano가 대표적인 비모드형 편집기
